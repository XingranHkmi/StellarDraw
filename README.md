# StellarDraw 课堂抽号机

> 面向课堂的抽卡式随机抽号工具：用二次元抽卡的仪式感，做一件**不许拖慢课堂**的事。

**v1.0.0** · Windows 10 / 11 · Python 3.13 + pywebview(WebView2) + 原生 HTML/CSS/JS · 单文件 exe · 完全离线

---

## 一、简介

老师在课堂上随机点人回答问题，传统做法有三个痛点，本项目的设计全部围绕它们展开：

| 痛点     | 表现               | 本项目的应对                              |
| ------ | ---------------- | ----------------------------------- |
| 公平性存疑  | "老师你是不是故意的"      | 卡牌滑出 + 3D 翻转，随机过程可视化                |
| 重复率不可控 | 有人被连抽三次，有人一次没被抽到 | **去重模式**：一轮内全班每人最多被抽中一次，抽完自动开新一轮并提示 |
| 课堂气氛平淡 | 点名环节毫无波澜         | 看板娘三态 + 粒子光效 + 合成音效，把点名变成课堂的"提神点"   |

贯穿始终的一条主线是 **氛围感 vs 课堂效率**：装饰永远不拦截操作路径。所有动画总耗时控制在 1.2 秒内，并提供一个一键退路（**简洁视图**）。

---

## 二、核心特性

**抽号**

- 两种模式：**抽取 1 次** / **抽取 5 次**（5 张牌同时滑出，**点哪张翻哪张**，不点的一直保持卡背）
- 结果卡**分两行**：上行学号（小字）、下行姓名（大字）；学号留空时只显示姓名并垂直居中
- 去重开关一键切换：开启时一轮内不重复；抽完自动重置并提示；**同名不同学号视为两个不同的人**
- 名单管理：多个班级档案自由切换 / 重命名 / 删除，当前班级重启自动恢复
- 名单录入三条路径：逐条手动添加、**批量粘贴**（每行一条，兼容 `学号,姓名`、`学号 姓名`、纯姓名）、**导入 CSV**
- **简洁视图**：一键启动你在设置里指定的任意 exe，与主程序完全独立、不传数据不共享状态
- 名单为空、外部程序路径失效、CSV 格式非法等边界情况均有明确提示与引导，不崩不卡

**氛围**

- 5 层错位牌堆、卡牌滑出、点击后 Y 轴 3D 翻转（中途可见卡牌厚度感）
- 看板娘三态：待机 / 抽取中 / 出结果，可在设置中关闭
- 加载图标随抽取状态同步旋转；音效由 Web Audio API 实时合成，**不依赖任何音频文件**

**特殊效果**

| 按钮   | 作用                                                             | 生效范围             |
| ---- | -------------------------------------------------------------- | ---------------- |
| 增大概率 | 勾选若干学生，其被抽中的权重变为其他人的 **3 倍**                                   | 持续生效，直到主动取消或切换班级 |
| 结果漂移 | 选「轻移 +1 / 重移 +3」，下一次翻牌**先原样显示结果，闪一下之后再变成偏移后的学生**               | 只对下一次抽取生效        |
| 课堂叫醒 | 选音量（40% / 60% / 90%）确认后，下一次翻牌时播放 bingo 五连音，**只改本次发音音量，不动系统音量** | 只对下一次抽取生效        |

> 三个彩蛋**全部只在进程内存中生效，不写入任何配置文件**，关闭软件即清空。  
> 抽取历史同样不落盘，只在界面上显示最近几条。

## 三、老师怎么用

### 1. 启动

- **从release下载打包版**：双击 `StellarDraw.exe` 即可，无需安装 Python。  
  首次运行需系统已安装 **WebView2 运行时**（Windows 11 通常自带；Windows 10 一般随 Edge 安装）。缺失时软件会弹提示并给出官方下载入口。
- **源码版**：自己配置环境，直接`uv sync`就能用了。

窗口默认按 **2560×1440 物理像素**打开（4K 一体机上约占屏幕 44%，保证教室后排看得清），并自动按系统缩放折算后在主显示器工作区内居中；最小可用尺寸 1280×720。

### 2. 准备名单

点击左下角 **⚙ 设置** → **名单管理**页：

1. 新建一个班级（例如"高一(3)班"），可以建多个班级随时切换；
2. 三选一录入：**+ 添加学生** 逐条加 / **批量粘贴** 从 Excel 整列贴过来 / **导入 CSV**；
3. 也可以点 **创建 CSV 模板**，在 `data/` 目录生成标准模板，用 Excel 填好后再导入。

**CSV 格式规范**

```csv
Num,Name
1,张小雨
2,李雷
```

- 表头固定为 `Num,Name`（大小写不敏感，也兼容中文表头"学号/姓名"）；
- `Num`（学号）**可留空**，留空时结果卡不显示学号行；`Name`（姓名）必填，为空的行整行跳过；
- 模板为 **UTF-8 带 BOM** 编码（保证双击用 Excel 打开中文不乱码）；导入时自动按 `utf-8-sig → utf-8 → gbk` 顺序嗅探编码，Windows 下常见的 GBK 文件也能直接读；
- 当前班级已有名单时，导入前会弹出选择框让你明确选 **覆盖** 还是 **追加**，不会静默覆盖。

### 3. 抽号

点 **抽取 1 次** 或 **抽取 5 次** → 卡牌从左上牌堆滑到中央 → 点卡背翻开 → 读出学号与姓名。  
抽取过程中按钮会自动禁用，避免连点导致动画错乱。

### 4. 界面上的开关

| 位置         | 作用                                     | 是否记住   |
| ---------- | -------------------------------------- | ------ |
| 左下 ⚙       | 打开设置面板（名单管理 / 抽取规则 / 外观音效 / 外部程序 / 关于） | —      |
| 左下 🔊 / 🔇 | **一键静音：只对本次运行生效**，不改设置、不写盘             | ❌ 重启恢复 |
| 左下「简洁视图」   | 启动你指定的外部程序（先用「浏览...」选一次路径即可，路径会记住）     | ✅      |
| 设置 → 抽取规则  | 去重模式开关                                 | ✅      |
| 设置 → 外观音效  | 音效默认开关（决定软件启动时的音效状态）、音量、看板娘显隐          | ✅      |
| 设置 → 外部程序  | 简洁视图所用的 exe 路径                         | ✅      |

> 静音按钮与设置里的音效开关是**两层语义**：设置里的是"默认值"，启动时继承；主界面按钮只临时覆盖本次运行 —— 这样老师上课随手静音，不会把软件的默认偏好改掉。

### 5. 数据在哪 / 隐私

- 所有数据都在**软件同目录的 `data/` 文件夹**里，绿色免安装、不写注册表：

```
data/
├── config.json              # 配置（去重、音效、看板娘、外部程序路径、当前班级）
├── rosters/<班级名>.json     # 各班级名单
└── roster_template.csv      # CSV 模板
```
