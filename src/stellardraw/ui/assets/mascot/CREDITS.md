- ✅ **允许** — 个人自用：本地运行、课堂演示、本项目内置。
- ❌ **禁止** — 搬运到其他平台、二次转载、二次分发、改图（**含去除水印**）。
- ⚠️ 因此本项目**刻意保留**素材上的作者水印，**不做**任何擦除处理。

  **必须先取得作者授权**，或改用自制 / 可商用素材。

## 素材替换指引

看板娘走「三张图叠放 + `data-state` 切换 opacity」的方案（见 `README`/PRD F-14）：

1. 准备三张同比例（**2:3**）图片，建议 ≥400×600，PNG 透明或纯色底皆可；
2. 覆盖 `mascot_idle.png` / `mascot_loading.png` / `mascot_result.png`；
3. 不需要改任何 HTML / CSS —— 容器比例与 `object-fit: contain` 会自动适配。

> 注意：`docs/PRD.md` F-14 契约要求「替换同名素材即可更换形象」，
> 因此**务必保持文件名与 2:3 画布比例不变**，否则顶部布局会跳动。
